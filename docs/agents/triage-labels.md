# Triage Labels

The canonical triage labels for this repo:
- `needs-triage`: A new issue that has not yet been processed.
- `needs-info`: Waiting on clarification or further input.
- `ready-for-agent`: Fully specified and ready for an autonomous agent to implement.
- `ready-for-human`: Requires manual intervention or human review.
- `wontfix`: Out of scope or rejected.
